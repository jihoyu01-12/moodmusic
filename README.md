# 🎧 MOOD MUSIC

### 기분과 상황에 맞는 음악 추천 웹사이트

## 1. 프로젝트 소개

MOOD MUSIC은 사용자의 기분과 상황에 맞는 음악을 쉽게 찾을 수 있도록 제작한 웹사이트입니다. 공부, 휴식, 운동 등 다양한 상황에 어울리는 음악을 탐색할 수 있습니다.

## 2. 기획 목적

- 기분과 장르에 따른 음악 탐색
- 검색 및 좋아요 기능으로 사용자 편의성 향상
- HTML, CSS, JavaScript를 활용한 웹 개발 기초 학습

## 3. 주요 기능

- **기분별 추천:** 공부, 휴식, 운동, 기분 전환
- **음악 검색:** 노래 제목 및 가수 검색
- **장르 필터:** POP, INDIE, LO-FI, R&B
- **좋아요:** 마음에 드는 음악 목록 관리
- **테마 변경:** 밝은 테마와 어두운 테마
- **반응형 디자인:** PC 및 모바일 화면 지원

## 4. 페이지 구성

- **Home:** 사이트 소개
- **Moods:** 기분별 음악 선택
- **Discover:** 음악 검색 및 필터링
- **Playlists:** 상황별 음악 목록
- **Favorites:** 좋아요한 음악
- **About:** 사이트 소개 및 제작 목적

## 5. 사용 기술

- HTML5: 웹 페이지 구조
- CSS3: 디자인 및 반응형 레이아웃
- JavaScript: 검색, 필터링, 좋아요 등 기능 구현
- Git & GitHub: 코드 관리 및 저장

## 6. 파일 구성

## 7. AI 활용

AI를 활용해 프로젝트 기획, 코드 구현, 오류 해결 및 기능 개선을 진행합니다.

## 8. 기대 효과

HTML, CSS, JavaScript의 기초를 실습하고 사용자와 상호작용하는 웹사이트를 제작하며 프런트엔드 개발 능력을 향상합니다.

> **참고:** 음악 데이터는 예시이며, 실제 음악 재생 기능은 제공하지 않습니다.
